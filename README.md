# land-water-transformation-bot
This project is an amphibious robot featuring a custom aluminum chassis and unique 3D-printed wheels that can transform their shape. A central mechanism, actuated by stepper motors and lead screws, reconfigures the wheels from a round shape for land travel into propellers for water traversal.
